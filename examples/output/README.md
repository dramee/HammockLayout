# Результаты работы алгоритма

Гамачные представления входных графов из каталога [examples](..) — иерархические
GraphML-файлы (XML), построенные библиотекой. Каждый простой и составной гамак,
в том числе одновершинный, записан узлом `<node id="hammockK">` с вложенным `<graph>`.

| Файл | Что показывает |
|------|----------------|
| `if_then_else.graphml` | ветвление: весь граф (составной гамак) ⊃ простой гамак ветвления ⊃ гамаки ветвей |
| `nested_loops.graphml` | вложенные циклы: внешний цикл ⊃ внутренний цикл ⊃ ветвление |
| `sequence_in_branch.graphml` | последовательность в ветке: разложимый гамак {mul1, mul2} в представление не входит, его части — отдельные простые гамаки |

Атрибуты кластера `label`, `hammock.kind`, `hammock.start`, `hammock.end`,
`hammock.size`, `hammock.depth` описаны в корневом
[README](../../README.md#формат-выходного-graphml). Файлы открываются в yEd,
Gephi и других редакторах, поддерживающих GraphML.

Файлы являются эталонами для тестов `Examples/Example.*`
([examples_test.cpp](../../tests/examples_test.cpp)). После изменения алгоритма их
перегенерируют запуском тестов с переменной окружения `HAMMOCK_UPDATE_EXAMPLES=1`.
